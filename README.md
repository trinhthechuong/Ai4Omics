# AI for Omics: critical reading and reproduction assignment

Five melanoma transcriptomic datasets. One is the real cohort of Liu et al.; the other four are
synthetic copies of it. The assignment asks how much of the published biology survives in the copies.

## 1. Background

Liu, Schilling et al. profiled 121 metastatic melanoma tumours by RNA-seq before treatment with
anti-PD1 immunotherapy and asked which transcriptomic features predict response. Their principal
transcriptomic findings were that MHC class II genes are expressed more highly in responders, that
this signal is confined to patients previously treated with ipilimumab, and that a three-feature
logistic regression separates patients who will progress from those who will not.

> Liu D., Schilling B., Liu D. et al. *Integrative molecular and clinical modeling of clinical
> outcomes to PD1 blockade in patients with metastatic melanoma.* **Nature Medicine** 25, 1916-1927
> (2019). <https://doi.org/10.1038/s41591-019-0654-5>

Patient-level genomic data cannot be shared freely: cohorts such as this one are deposited in
controlled-access repositories (dbGaP, EGA), and obtaining access requires an application that
typically takes several months. One proposed solution is to release a synthetic copy of the cohort,
that is, a table with the same variables and the same number of rows, generated by a model fitted to
the real data and containing no real patient. The question examined here is whether such a copy still
supports the same scientific conclusions.

## 3. Data dictionary

Each file contains 121 rows (patients) and 18,814 columns.

| Columns | Content |
|---|---|
| `Patient_ID` | row index, `P001` to `P121`. Carries no meaning. |
| columns 1 to 54 | clinical and tumour-genomic variables |
| columns 55 to 18,814 | gene expression, one column per gene symbol, in TPM |

Variables used in the assignment:

| Variable | Meaning |
|---|---|
| `BR` | best RECIST response: `CR`, `PR`, `SD`, `PD` |
| `daysBiopsyAfterIpiStart` | `noIpi`, `preIpi`, `postIpi`: timing of the biopsy relative to ipilimumab |
| `PFS`, `progressed` | progression-free survival in days, and the event indicator |
| `OS`, `dead` | overall survival in days, and the event indicator |
| `purity`, `ploidy`, `heterogeneity`, `CNA_prop` | tumour genomic characteristics |
| `total_muts`, `nonsyn_muts`, `clonal_muts`, `subclonal_muts`, `total_neoantigens` | mutation and neoantigen counts |
| `Tx_Start_LDH` | serum LDH at the start of anti-PD1 therapy |
| `LN_Met` | lymph-node metastasis, 1 or 0 |
| `MHCI_Amp`, `TAP2_Amp` | amplification of the MHC-I locus and of TAP2 |

Group definitions used throughout:

* **responder**: `BR` is `CR` or `PR`
* **progressor**: `BR` is `PD`
* **post-ipilimumab subgroup**: `daysBiopsyAfterIpiStart == "postIpi"`

## 5. Getting started

```python
import pandas as pd

d = pd.read_csv("data/D1.csv", index_col=0)
clinical = d.iloc[:, :54]
expression = d.iloc[:, 54:]                   # 18,760 genes, TPM

mhc = pd.read_csv("data/mhc_gene_sets.csv")
gene_sets = {s: g["Gene"].tolist() for s, g in mhc.groupby("GeneSet")}
```

Single-sample gene set scores are computed with `gseapy`:

```python
import gseapy as gp
res = gp.ssgsea(data=expression.T, gene_sets=gene_sets, sample_norm_method="rank",
                permutation_num=0, outdir=None, no_plot=True, min_size=1)
scores = res.res2d.pivot(index="Name", columns="Term", values="ES").astype(float)
```

Packages used: `pandas`, `numpy`, `scipy`, `statsmodels`, `scikit-learn`, `gseapy`, `lifelines`,
`matplotlib`, `seaborn`. All install with `pip` and all work on Google Colab.
